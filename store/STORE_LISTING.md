### Detailed description

```
Staring at a screen all day dries out your eyes and tires the muscles that keep them focused. Optometrists suggest a simple habit called the 20-20-20 rule: every 20 minutes, look at something about 20 feet (6 meters) away for 20 seconds.

Eye Rest makes that habit automatic.

WHAT IT DOES

• Every 20 minutes a calm window appears with a countdown ring and a simple picture of what to do — look from your screen to something far away. It closes itself when the 20 seconds are up.
• Prefer something quieter? Switch to a plain system notification, or use both.
• A built-in Pomodoro timer runs focus sessions and real breaks: 25 minutes of work, 5 minutes off, and a longer break after four rounds. The toolbar icon shows the minutes left in the current phase.
• Five gentle built-in sounds — Chime, Bell, Marimba, Drop and Soft. Preview them in settings and pick the one you like, or turn sound off entirely.
• A small chart in the popup shows how many breaks you actually took today and over the past week. Only completed breaks count — skipping one does not.
• Step away from the computer for a few minutes and the timer quietly restarts, so you are not nagged the moment you sit back down.

EVERYTHING IS ADJUSTABLE

Reminder interval, rest length, Pomodoro focus and break durations, cycles before a long break, notification style, sound. Changes save the moment you make them.

PRIVACY

Eye Rest works entirely offline. There is no account, no sign-in, no analytics, and no server — the extension makes no network requests at all. Your settings and break counts are stored by Chrome on your own device. Nothing is collected, and nothing is sold or shared.

The extension does not read, modify, or even have permission to access the pages you visit.

OPEN AND SIMPLE

No frameworks, no trackers, no bundled libraries — just a few small files of plain JavaScript. The rest sounds are generated by the browser itself, so the extension ships without a single audio file.

Available in 16 languages — English, Russian, Spanish, Portuguese (Brazil), German,
French, Italian, Japanese, Korean, Simplified and Traditional Chinese, Hindi, Arabic,
Turkish, Vietnamese and Indonesian. The interface follows your Chrome language.
```

## Privacy tab

### Single purpose description
```
Eye Rest reminds the user to take regular eye and stretch breaks on a timer, using the 20-20-20 rule, and provides an optional Pomodoro timer for the same purpose.
```

### Permission justifications

**alarms**
```
Used to schedule the break reminders and Pomodoro phase changes. Chrome unloads the extension's background worker when idle, so alarms are the only reliable way to fire a timer later.
```

**notifications**
```
Used to show the break reminder as a system notification when the user selects that reminder style, and to announce Pomodoro phase changes.
```

**storage**
```
Used to save the user's own settings (reminder interval, rest length, Pomodoro durations, sound choice) and the local count of completed breaks. Stored on the user's device only.
```

**idle**
```
Used to detect that the user stepped away from the computer, so the reminder timer restarts instead of firing immediately when they come back.
```

**Remote code**: No, the extension does not use remote code. All JavaScript is included in the package.

### Data usage disclosures

Check **no** boxes in the data collection list. The extension collects none of:
personally identifiable information, health information, financial information,
authentication information, personal communications, location, web history,
user activity, or website content.

Then tick all three certification checkboxes:
- I do not sell or transfer user data to third parties, apart from the approved use cases
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- I do not use or transfer user data to determine creditworthiness or for lending purposes

### Privacy policy URL
Not required while the extension collects no user data. If the dashboard asks for
one anyway, publish `store/PRIVACY.md` as a public page (for example a GitHub Pages
or Gist URL) and paste that link.

## Before uploading

1. Rebuild the package so the version in `manifest.json` matches what you are shipping.
2. Upload the zip on the **Package** tab.
3. Fill in the fields above, attach the graphics, save the draft.
4. Submit for review. First reviews typically take a few business days.

Note: a one-time 5 USD developer registration fee applies to a new Chrome Web Store
developer account.
