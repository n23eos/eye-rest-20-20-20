## Как добавить перевод листинга

1. Developer Dashboard → расширение → **Store listing**
2. Вверху выпадающий список языков → выбрать язык → **Add language**
3. Вставить короткое описание из блока выше
4. Полное описание для этого языка можно оставить английским: магазин
   покажет его, если перевода нет. Английский вариант — в `STORE_LISTING.md`.

Языки, для которых перевод листинга не добавлен, увидят английскую карточку,
но сам интерфейс расширения всё равно будет на их языке.
