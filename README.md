# Отдых для глаз 20-20-20

Chrome-расширение (Manifest V3): напоминает посмотреть вдаль по правилу 20-20-20 —
каждые 20 минут смотреть на объект в ~6 метрах (20 футов) по 20 секунд.
Плюс помодоро-таймер и статистика отдыхов.

## Возможности

- **Окно с инструкцией** (по умолчанию): всплывает поверх работы, показывает
  кольцевой отсчёт и схему «экран → ≈6 м → окно с деревом». Закрывается само,
  можно пропустить кнопкой или Esc.
- **Выбор типа напоминания**: окно с инструкцией / системное уведомление / оба сразу.
- **Все таймеры настраиваются**: интервал напоминаний, длительность отдыха,
  работа и перерывы помодоро, число циклов до длинного перерыва.
- **Помодоро**: работа → короткий перерыв, после нескольких циклов — длинный.
  На иконке минуты до конца фазы (красный = работа, зелёный = перерыв).
  На перерыве открывается то же окно отдыха.
- **Пять звуков на выбор**: Колокольчик, Колокол, Маримба, Капля, Мягкий.
  В начале отдыха ноты идут вверх, в конце — те же вниз. Всё генерится на лету
  через Web Audio, ни одного mp3 в проекте. В настройках есть кнопка
  «▶ Прослушать». Звук целиком отключается галочкой.
  В режиме «только системное уведомление» звук играет сама система.
- **Статистика отдыхов**: в попапе — сколько сегодня и всего, плюс столбики за 7 дней.
  Считаются только досчитанные до конца отдыхи: нажал «Пропустить» — не засчитано.
  История хранится 90 дней, сброс — в настройках.
- **Два языка**: английский и русский через chrome.i18n. Язык интерфейса
  следует за языком Chrome, английский — по умолчанию.
- Если отошёл от компьютера на 5+ минут — отсчёт интервала начинается заново.
- Режимы взаимоисключающие: запустил помодоро — глазные напоминания выключаются;
  включил глаза — помодоро останавливается.

## Значения по умолчанию

| Параметр | По умолчанию |
|---|---|
| Напоминание для глаз | каждые 20 мин |
| Длительность отдыха | 20 сек |
| Тип напоминания | окно с инструкцией |
| Звук | включён, «Колокольчик» |
| Помодоро: работа | 25 мин |
| Помодоро: короткий перерыв | 5 мин |
| Помодоро: длинный перерыв | 15 мин |
| Циклов до длинного перерыва | 4 |

## Установка (режим разработчика)

1. Открой в Chrome адрес `chrome://extensions`
2. Включи справа сверху **Режим разработчика** (Developer mode)
3. Нажми **Загрузить распакованное расширение** (Load unpacked)
4. Выбери эту папку (`chrome_extention_eyes`)
5. Закрепи иконку расширения на панели (пазл → пин)

После изменения файлов нажми ⟳ на карточке расширения, чтобы применить.

## Настройки

Иконка расширения → **⚙ Настройки** (или `chrome://extensions` → Подробнее →
Параметры расширения). Всё сохраняется сразу, кнопка «Сохранить» не нужна.
Значения вне разумных границ подтягиваются к ближайшему допустимому.

Кнопка **«Показать окно отдыха сейчас»** в настройках (и «Проверить сейчас»
в попапе) показывает окно немедленно — удобно посмотреть, как оно выглядит,
не дожидаясь таймера.

## Как быстро проверить

Отдельного тестового режима нет — он не нужен: в настройках минимальные значения
и так короткие. Поставь интервал **1 мин** и отдых **5 сек**, посмотри, как работает,
потом верни обратно. Либо нажми «Проверить сейчас» в попапе — окно откроется сразу.

## Если уведомления не приходят (macOS)

Актуально только для типа «системное уведомление» — окно с инструкцией
работает независимо от системных настроек.

1. Системные настройки → Уведомления → Google Chrome → разрешить
2. Проверь, что не включён режим «Не беспокоить» (Focus)
3. Логи: `chrome://extensions` → ссылка **service worker** под расширением →
   вкладка Console, строки `[eyes] ...`

## Файлы

- `manifest.json` — описание расширения (Manifest V3)
- `_locales/en`, `_locales/ru` — переводы интерфейса
- `i18n.js` — подстановка переводов в разметку
- `settings.js` — настройки по умолчанию, чтение/запись, валидация
- `stats.js` — счётчик отдыхов по дням, очистка старой истории
- `sound.js` — пять звуковых пресетов через Web Audio
- `background.js` — таймеры (chrome.alarms), помодоро, открытие окна отдыха
- `rest.html/css/js` — окно отдыха с инструкцией 20-20-20
- `options.html/css/js` — страница настроек
- `popup.html/css/js` — быстрые действия по клику на иконку
- `icons/` — иконки (помидор с глазами)

Настройки лежат в `chrome.storage.sync` (синхронизируются между устройствами),
статистика и состояние помодоро — в `chrome.storage.local`.

## Публикация в Chrome Web Store

В папке `store/` лежит всё для листинга:

- `STORE_LISTING.md` — название, короткое и полное описание, категория,
  обоснования разрешений и ответы для вкладки Privacy (всё на английском)
- `PRIVACY.md` — политика приватности, если магазин попросит ссылку
- `screenshots/` — 5 скриншотов 1280×800, 24-битный PNG без альфы

Промо-плитки и иконка магазина — в `chrome_web_store_assets/`.
